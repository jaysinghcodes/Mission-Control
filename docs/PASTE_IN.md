# Paste this into OpenClaw

You are the OpenClaw agent. Your operator pasted this file so the Mission Control dashboard comes up. In one message, show the plan: run the installer, report the URL, register, and send a heartbeat. Wait for one yes. Then do those steps. Do not ask the operator to type commands, tokens, or ports. Do not invent secrets. Do not print token values. If a command fails, stop and report the error before any different command.

## Run the installer

From this repository, run `bash install.sh`. If you are not in a checkout, use the curl command at the top of the README. The same command is the first command in the README section Install and run. That command runs the same script. Longer installer notes are in [INSTALL.md](INSTALL.md).

The script is Docker first. If Docker is missing, it says so and uses Node.js 20.17 or later and Postgres 16. Docker installs do not need Node on the host. The Compose health wait polls /health with curl. If curl is missing on the host, it runs curl inside the api container with docker compose exec. That wait does not call host Node, npm, or npx. The Compose install then runs doctor inside the api container with docker compose exec, with or without Node on the host. That check does not call host Node, npm, or npx. When docker compose up cannot bind a port, the installer prints that the port is used by another program, names MC_API_PORT, MC_WEB_PORT, MC_DB_PORT, or MC_REMOTE_PORT, and exits 1. CI runs that script with Docker Compose on Ubuntu, and on the native path on Ubuntu and macOS. The macOS runner does not use Docker. It writes a random ingest token, a dashboard password hash, and a session secret to `.env` and sets that file to mode 600, only when `.env` is missing. Long build output goes to `install.log`. The screen shows one progress line and names that file. The run ends with the URL, the password on the first install, and the reset command. A plain second run does not print or change the password. It leaves every other value in `.env` unchanged and writes `MC_INSTALL_MODE` when that key is missing. It fills a missing password hash or session secret without changing other keys. It resolves ports from the shell, then `.env`, then the defaults, and writes `DATABASE_URL` with that `MC_DB_PORT` on a new file. The web port is `MC_WEB_PORT` (default 5173). The native API listen port is `PORT` (default 3000). `MC_API_PORT` is the Compose host port and is accepted on the native path when `PORT` is unset. When both are set, `PORT` wins. The printed URL uses `MC_WEB_PORT`. A later run updates that URL only when a new `MC_DB_PORT` is passed and the URL is still the stock localhost port. A custom URL is left as is. Before Compose starts, it creates the host docs directory (`DOCS_ROOT`, or `data/docs`) as the user running the script. That user can delete the checkout. It runs doctor and prints the dashboard URL. Use that URL. Do not choose another one.

When the `openclaw` command is on PATH, the same command installs the bridge schedule. It does not start the OpenClaw gateway. Remove the schedule later with `bash install.sh --uninstall-schedule`. A steady state run starts `openclaw` once, for sessions. Agents, cron, devices, nodes, the models list, and the CLI version are cached and fetched again when `openclaw.json` changes, a value is missing, or once an hour. See [A light run](../bridge/README.md#a-light-run) for the bridge profile flag. If `openclaw` is not on PATH, the installer skips that step and still finishes. `npm run seed:demo` fills sample data and does not need OpenClaw. On this Compose path, run `npm ci` in the checkout before `npm run seed:demo` or `npm run seed:clear`. Without that install, prisma is not found and the seed command fails. `npm run doctor` is the same check the installer runs at the end. On Compose it checks MC_API_PORT, MC_WEB_PORT, MC_DB_PORT, and MC_REMOTE_PORT, and it names a missing, stopped, or paused web service the same way as db and api. Each problem prints on its own line. If that check says this user lacks permission to use the Docker socket, add the user to the docker group and start a new login session.

The gateway check is optional. Under Compose the bridge checks 127.0.0.1 and posts `gateway.snapshot` with `x-ingest-token`. System shows Unknown when that report is missing or older than `GATEWAY_STATUS_MAX_AGE_MS` (default 600000). A report stored before the API process started is Unknown too, so a recreated API container shows Unknown until the next bridge report. A future checkedAt is counted from the time the API stored the report. A native install, or an explicit `OPENCLAW_GATEWAY_HOST`, probes that host on `OPENCLAW_GATEWAY_PORT` (default 18789). Do not start the gateway unless the operator asked.

The bridge posts each agent provider and model from `~/.openclaw/openclaw.json`. When that file has no model, it runs `openclaw models list`. System shows those rows. With no bridge, the page says "No providers found yet. Run the bridge to detect them."

Usage prices session tokens from `config/prices.json`. Copy a model into `config/prices.local.json` to change that price without a rebuild. A provider `costUsd` wins when OpenClaw reports one. Ollama costs $0.00. A model with no price shows `Price not set`. When any model in the period has no price, the System header and Usage show the known total and `Price not set for some models`. `deepseek-v4-flash` is priced in the shipped file.

## Report the URL

Pass the URL and the password to the operator privately. Never post the password in a shared channel. Tell your operator the URL the installer printed. On Compose, also tell them the tunnel port in that summary. On the native path that summary points at docs/REMOTE.md. The reset command is in the installer summary. Under Compose it is `docker compose exec api npm run password:reset`. On the native path it is `npm run password:reset`. `bash install.sh` sets `MC_INSTALL_MODE` to compose or native in `.env`. On compose, a host `npm run password:reset` runs inside the api container and does not write a host file. If the api is not running, run `docker compose up -d` first. The command prints a new password once only after the new hash is read back and every session is revoked. With no `MC_INSTALL_MODE` in `.env`, a host `npm run password:reset` checks Docker for this checkout's Compose containers and its mc-auth volume. If it finds either, or Docker does not answer, it refuses and writes nothing. Run `bash install.sh` again, or start Docker when it did not answer, then run the reset again. With no docker command, or no Compose trace, the native reset runs. If the new hash cannot be read back, the command exits 3 and says the password may have changed. Run the reset again to set a new one. There is no HTTP route for it. The local URL is the owner port. SSH uses that port. On Compose, Cloudflare Tunnel and Tailscale Serve use the tunnel port. The default is 3011 (`MC_REMOTE_PORT`). The native path does not listen on that port. The three laptop paths are in [REMOTE.md](REMOTE.md). Login is required on each of them for a Compose install. Say that `INGEST_TOKEN` lives in `.env` and that the dashboard password was printed once. Do not print the token or the password hash. If doctor prints a failing line, include that line. A missing OpenClaw command is an info line. When a schedule is installed, a sync older than `MC_BRIDGE_STALE_SECONDS` fails doctor. On Compose the dashboard asks for that password, because the API sees the Docker network and not loopback. The local port and the tunnel port do not share a login lock. Log out ends every session, so a copied cookie stops working after a restart. Too many wrong passwords ask the operator to wait. `npm run login:reset` clears that lock. Under Compose run `docker compose exec api npm run login:reset`. On a native install, loopback stays open. Under Compose this machine still asks. A forwarded header does not make a caller loopback. Agent ingest with `x-ingest-token` is not part of that wait.

## Register and heartbeat

Read `INGEST_TOKEN` from `.env`. Send it as the header `x-ingest-token`. Do not print it. Call the API on the port this run already chose. On Docker the installer prints `Waiting for the API health check on port`. On the native path doctor prints `pass ports: Port`. Use `127.0.0.1` and that port. POST `/agents/register` with your own id and name, then POST `/agents/<id>/heartbeat`. The request shapes are in [API.md](API.md#410-register-heartbeat-and-delete). A 401 means the token is wrong, or that route is for the dashboard only. That line is in [API.md](API.md#41-auth). Do not choose a timezone, crew names, or a provider for the operator. The dashboard asks for a timezone, then the Mission Control crew or their own names, then confirms the detected provider. Skip finishes that open. Seat rules are in the README section [How crew seats work](../README.md#how-crew-seats-work). The operator can change any seat in Settings.

## Tickets and runs

Create work with POST /tickets. Send `x-ingest-token` and `x-actor-id` set to your registered agent id. The body is `{ title }` plus optional `status` (`backlog` or `todo`), `priority` (`high`, `med`, or `low`), `assignee`, `tags`, `projectId`, and `description`. A created ticket answers 201. Activity stores that agent id. Move it with PATCH /tickets/<id> and the same headers. A token may set `status`, `assignee`, `title`, and `description`. After create, `status` may also be `build`, `qa`, `review`, or `done`. There is no ticket delete route. Every other dashboard write needs loopback or a session cookie.

Record a run with POST /runs. The body is `{ name }` plus optional `agent`, `ticketId`, and `status` (`queued`, `running`, `done`, `failed`, or `needs_approval`). A created run answers 201. Update it with PATCH /runs/<id>. Send the same `x-ingest-token` header. The field tables are in [API.md](API.md#44-tickets-your-units-of-work) and [API.md](API.md#46-runs).

## Stop

Tell your operator the dashboard URL, whether the bridge schedule was installed or skipped, and the register and heartbeat status codes. The short guide is [OPENCLAW_ONBOARDING.md](OPENCLAW_ONBOARDING.md). Do not add another schedule.
